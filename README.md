# Unemployment Rate Analysis

An exploratory data analysis (EDA) project analyzing unemployment trends across different regions and timeframes, completed as part of the **CodeAlpha Data Science Internship (Task 2)**.

---

## 📌 Project Overview

Unemployment is a critical socio-economic indicator. This project explores historical unemployment data to uncover patterns, regional disparities, and seasonal fluctuations, especially highlighting changes in employment rates during key periods (such as economic shifts or lockdowns).

### Key Objectives:
- Analyze distribution and central tendencies of estimated unemployment rates.
- Identify regions/states with the highest and lowest unemployment rates.
- Evaluate the impact of economic events over time using time-series trend visualizations.
- Understand the relationship between unemployment rate, employment numbers, and labor participation rates.

---

## 🛠️ Tech Stack & Libraries

- **Language:** Python
- **Environment:** Jupyter Notebook
- **Data Manipulation:** `pandas`, `numpy`
- **Data Visualization:** `matplotlib`, `seaborn`, `plotly`
